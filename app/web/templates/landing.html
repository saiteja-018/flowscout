02 / The method

Reproduce. Prove. Prevent.

01

Reproduce

Creates a logical sandbox, deploys the ShopDemo fixture, and drives Chromium through the checkout. A controlled HTTP 503 at step 7 forces the recovery path instead of hiding it.

  • Structured browser actions, never page-supplied code
  • Fresh-sandbox recovery on a mid-task failure
  • Deterministic fixture and scripted planner
02

Prove

Captures the action log, screenshots, command audit, lifecycle trace, hashes, and git provenance. The defect is classified before any claim is made.

  • 50 structured actions in the recorded mock run
  • 28 lifecycle events, including the 503 and retry
  • Every artifact linked and verifiable
03

Prevent

Generates a reproduction spec and a regression spec, then runs a four-case matrix. The reproduction must fail on the fixed build; the regression must fail on the broken build.

  • {{ matrix.met }}/{{ matrix.total }} expectations met
  • Broken and fixed modes both exercised
  • Cleanup verified after success and failure
!

Containment, not trust
