What happens

The real execution path.

  1. 01
    Validate target

    Scheme, DNS answers, ports, and private-address rules are checked before anything launches.

  2. 02
    Create sandbox

    Mock mode simulates the lifecycle; live mode creates a real Celesto computer and registers ownership.

  3. 03
    Explore with Chromium

    Same-origin links, safe fields, and non-destructive controls. Screenshots and browser diagnostics are captured.

  4. 04
    Detect and save

    Issues become evidence. Validated actions become saved tests with assertions.

  5. 05
    Clean up

    Deletion is attempted in finally and confirmed by the provider. Protected IDs are preserved.

Guardrails

  • No credentials in URLs or browser forms
  • No destructive, payment, or account actions
  • No arbitrary AI-generated code execution
  • No silent mock fallback for a live run
  • Live mode blocks private networks and metadata targets
